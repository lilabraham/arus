# Kategori Default — Arus

Disusun untuk kebutuhan harian, jangka panjang, dan kerja/freelance di Indonesia (2026).
Dua level: **Kelompok → Kategori**. Laporan & anggaran bisa per kelompok atau per kategori.
Semua bisa diubah nama, diarsipkan, atau ditambah di layar Atur.

Ikon kategori = **monogram** 2 huruf dalam kotak berwarna kelompok (gaya logo bank di daftar
transfer). Tidak memakai emoji.

## Aturan Penting

- **Bukan pengeluaran → pakai Transfer:** isi saldo e-wallet, tarik tunai, menabung,
  beli investasi, bayar tagihan kartu kredit/paylater. Uangnya hanya pindah rekening.
- **Belanja pakai kartu kredit/paylater** = pengeluaran biasa dari rekening jenis `credit`.
- **Bunga/biaya** cicilan dan admin = pengeluaran di kelompok *Biaya Keuangan*.

## Rekening Default

Sesuai rekening yang dimiliki saat ini (saldo awal diisi saat pertama kali membuka aplikasi):

| Nama | Jenis | Monogram |
|---|---|---|
| Tunai | `cash` | TN |
| BCA | `bank` | BC |
| Mandiri | `bank` | MD |
| Jenius | `bank` | JN |
| DANA | `ewallet` | DA |

Rekening lain (GoPay, OVO, ShopeePay, kartu kredit, paylater, reksa dana, dll.) ditambah
manual di layar Atur. Nama bebas, tanpa daftar preset.

## Warna Kelompok

Setiap kelompok punya satu warna dari palet kategori di `docs/design-rules.md`
(`--cat-1` … `--cat-8`, dipakai bergiliran). Warna tidak pernah jadi satu-satunya
penanda: nama kategori selalu tertulis.
